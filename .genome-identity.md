# openclaw-module

- **Scopo**: Template/modulo "OpenClaw" — consolidamento del "Sacro Graal" (PRD + UI/architettura + modelli dati) di OpenClaw in 3 file master deterministici per un AI builder; fase solo-Markdown (zero codice), con upstream OpenClaw agganciato come submodule.
- **Stack**: Solo Markdown/documentazione in questa fase; upstream OpenClaw (`v2026.4.26`, commit `be8c246`) come git submodule in `upstream/openclaw`; design target: Open WebUI + HashiCorp Vault + Postgres/pgvector (RAG) — ma tutto non ancora implementato (solo requisiti).
- **Entry point**: `openclaw/1_PRD_Master.md` + `2_UI_Architecture_and_Flows.md` + `3_Data_Models_and_Mock_Data.md` (fonte di verita'), `openclaw/0_CORE_DA_COMPILARE.md` (editabile) + `0_CORE__SACRO_GRAAL__IMMUTABLE__20260518_215205.md` (backup read-only), `docs/CONTEXT.md`+`INGRESSO_PROMPT.md`, `core/` (vuota per ora).
- **Comandi**: Nessuno (nessun codice/runtime; solo Markdown). Gestione submodule: `git submodule update --init --recursive` per `upstream/openclaw`.
- **Maturita'**: experimental/template (fase 0: solo requisiti Markdown; implementazione non iniziata; decisioni default fissate ma codice assente).
- **Gotcha**:
  - E' un template documentale, non un'app: non cercare package.json/main — la "build" e' la lettura dei 3 file master da parte di un AI builder.
  - Il submodule `upstream/openclaw` va inizializzato (`--init --recursive`) altrimenti la cartella risulta vuota.
  - `0_CORE__SACRO_GRAAL__IMMUTABLE__*.md` e' read-only per contratto — non modificarlo mai; le modifiche vanno in `0_CORE_DA_COMPILARE.md` e poi si rigenera un nuovo backup.
  - Decisioni vincolanti gia' fissate (non arbitrabili): Open WebUI, Vault single-node, pgvector locale, audit append-only 365gg, porte 22+8080, subnet `172.29.0.0/16`/24 per tenant, naming `tnt_/node_/run_`.
- **Deploy**: N/A (template; il sistema target sara' VM-based con Vault/RAG — non ancora costruito).
- **Segreti**: Nessuno (nessuna credenziale; Vault sara' il secrets store a runtime ma non e' ancora configurato).
- **Dipendenze esterne**: upstream OpenClaw (submodule git); a regime Open WebUI, HashiCorp Vault, Postgres+pgvector (tutti design-only).
